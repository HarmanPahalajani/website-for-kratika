# Project Aurora V2

A cinematic, romantic storytelling website built with HTML, CSS, and vanilla JavaScript for GitHub Pages.

## Files
- index.html — semantic structure and content
- style.css — premium visual design and responsive layout
- config.js — reusable configuration constants
- effects.js — canvas-based atmospheric effects and interactions
- script.js — application logic for intro, reveal, and story interactions

## Run locally
Open index.html in a browser, or serve the folder with a simple static server.

## Deploy to GitHub Pages
1. Push this folder to a GitHub repository.
2. In repository settings, enable GitHub Pages.
3. Choose the main branch and root folder.
